# Umut Kayapınar — Portfolio

Premium, responsive portfolio concept built with vanilla HTML, CSS and JavaScript.

## Local preview
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Current sections
- Hero / introduction
- About and creative approach
- Selected works gallery
- Academic work, publications and events
- Contact section

## Before publishing
- Replace the illustrative CSS artwork with Umut Kayapınar's actual work images.
- Replace draft copy with verified biography and research information.
- Add real publication/event URLs and a working contact email.
- Confirm the preferred language setup (the current language control is a visual placeholder).
- Preview on mobile and desktop, then connect the domain/hosting only after approval.

No framework or build step is required.
